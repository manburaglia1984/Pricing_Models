Base rate curves 'SOFR Interpolation' generalised per currency

A trade prices off the latest curve published on or before the date it reads — the Trade Date for panels 3 and 4, the Pro Forma Issue Date for panel 2. Every rate below is editable in place; blank pillars are left untouched, so you can add a single data point for one date. Rates are percentages.

CSV columns are date plus the pillars the selected index publishes — 1m,3m,6m,12m for Term SOFR, 28d,91d,182d for TIIE, and so on; the template above always matches. Columns belonging to another index are ignored and named in the confirmation. Dates may be 2026-06-22, 6/22/2026, 22/06/2026 or 22-Jun-2026 — whatever Excel left behind — and semicolon files with comma decimals are read too. A row replaces any existing curve for that date. There is one curve per index — the pro forma block simply reads it at its own issue date.
